# Installation

Install the HeroBrain SDK for your preferred language.

---

## TypeScript / Node.js

### Requirements
- Node.js 18 or higher
- npm, yarn, or pnpm

### Install via npm

```bash
npm install @herobrain/sdk
```

### Install via yarn

```bash
yarn add @herobrain/sdk
```

### Install via pnpm

```bash
pnpm add @herobrain/sdk
```

### Verify Installation

```typescript
import { HeroBrain } from '@herobrain/sdk';

console.log('HeroBrain SDK loaded successfully!');
```

---

## Python

### Requirements
- Python 3.9 or higher
- pip

### Install via pip

```bash
pip install herobrain-sdk
```

### Install from source

```bash
git clone https://github.com/herobrain/sdk-python
cd sdk-python
pip install -e .
```

### Verify Installation

```python
from herobrain_sdk import HeroBrain

print('HeroBrain SDK loaded successfully!')
```
