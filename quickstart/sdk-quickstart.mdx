## TypeScript SDK

### Installation

<CodeGroup>
```bash npm
npm install @herobrain/sdk
```

```bash yarn
yarn add @herobrain/sdk
```

```bash pnpm
pnpm add @herobrain/sdk
```

### Quick Example

Create your first memory in 5 lines:

```typescript
import { HeroBrain } from '@herobrain/sdk';

const hb = new HeroBrain({ apiKey: process.env.HEROBRAIN_API_KEY });

// Create a memory
const memory = await hb.memories.create({
  content: 'Met with Sarah about Q4 roadmap planning',
  type: 'episodic',
  metadata: { person: 'Sarah', topic: 'Q4 Planning' }
});

console.log('Memory created:', memory.id);
```

<Tip>
  **Environment Variables** - Store your API key in `.env`: `HEROBRAIN_API_KEY=hb_live_...`
</Tip>

### Full Example: Chat App

```typescript app.ts
import { HeroBrain } from '@herobrain/sdk';
import express from 'express';

const app = express();
const hb = new HeroBrain({ apiKey: process.env.HEROBRAIN_API_KEY });

app.post('/api/chat', async (req, res) => {
  const { message, userId } = req.body;

  // Store user message as memory
  await hb.memories.create({
    content: message,
    type: 'episodic',
    metadata: { userId, source: 'chat' }
  });

  // Get AI response with memory context
  const response = await hb.chat.complete({
    message,
    includeMemoryContext: true,
    userId
  });

  res.json({
    message: response.message,
    citations: response.citations,
    memoriesUsed: response.memoriesReferenced
  });
});

app.listen(3000, () => console.log('Chat app running on port 3000'));
```

### Full Example: FastAPI Chat API

```python main.py
from fastapi import FastAPI
from herobrain import HeroBrain
from pydantic import BaseModel

app = FastAPI()
hb = HeroBrain(api_key="your_api_key_here")

class ChatRequest(BaseModel):
    message: str
    user_id: str

@app.post("/api/chat")
async def chat(request: ChatRequest):
    # Store user message as memory
    await hb.memories.create_async(
        content=request.message,
        type="episodic",
        metadata={"userId": request.user_id, "source": "chat"}
    )

    # Get AI response with memory context
    response = await hb.chat.complete_async(
        message=request.message,
        include_memory_context=True,
        user_id=request.user_id
    )

    return {
        "message": response.message,
        "citations": response.citations,
        "memories_used": response.memories_referenced
    }

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## Error Handling

<CodeGroup>
```typescript TypeScript
try {
  const memory = await hb.memories.create({
    content: 'Test memory'
  });
} catch (error) {
  if (error instanceof HeroBrainError) {
    console.error('API Error:', error.message);
    console.error('Status:', error.statusCode);
    console.error('Request ID:', error.requestId);
  }
}
```

```python Python
from herobrain import HeroBrain, HeroBrainError

try:
    memory = hb.memories.create(content="Test memory")
except HeroBrainError as e:
    print(f"API Error: {e.message}")
    print(f"Status: {e.status_code}")
    print(f"Request ID: {e.request_id}")
```
</CodeGroup>
