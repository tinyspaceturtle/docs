# MCP Quickstart

Get started with HeroBrain's MCP (Model Context Protocol) in under 5 minutes.

<Note>
  **What is MCP?** MCP is an open protocol that lets AI assistants like Claude Desktop access your HeroBrain memories securely.
</Note>

## Installation

Install the HeroBrain MCP client with one command:

<CodeGroup>
```bash npm
npx @herobrain/mcp install
```

```bash Direct
npx @herobrain/mcp install --platform=claude
```
</CodeGroup>

The installer will:
1. ✅ Detect your AI platform (Claude Desktop, Cursor, VS Code)
2. ✅ Start OAuth device flow for secure authentication
3. ✅ Configure MCP automatically
4. ✅ Restart your AI assistant

<Tip>
  **1-Click Setup** - No API keys to copy-paste. The installer handles everything.
</Tip>

## Manual Installation (Advanced)

If you prefer manual setup:

### Claude Desktop

1. Locate your Claude config file:
   - **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

2. Add HeroBrain MCP server:

```json claude_desktop_config.json
{
  "mcpServers": {
    "herobrain": {
      "command": "npx",
      "args": ["-y", "@herobrain/mcp", "serve"],
      "env": {
        "HEROBRAIN_API_KEY": "your_api_key_here"
      }
    }
  }
}
```

3. Restart Claude Desktop

### Cursor

1. Open Cursor settings (`Cmd/Ctrl + ,`)
2. Search for "MCP"
3. Add HeroBrain MCP configuration
4. Restart Cursor

### VS Code (Continue.dev)

1. Open VS Code settings
2. Navigate to Continue extension settings
3. Add MCP configuration
4. Reload window

## Using MCP Tools

Once installed, you can ask your AI assistant to:

<CodeGroup>



```text Get Insights
"What are my top priorities based on my HeroBrain memories?"
```
</CodeGroup>

## Authentication

### Device Flow OAuth (Recommended)

The MCP installer uses OAuth device flow for secure, passwordless authentication:

1. Installer generates a device code
2. Opens browser to `herobrain.ai/device`
3. You approve the request (one click)
4. MCP client polls for approval
5. Receives API key automatically

<Note>
  **No Copy-Paste** - API keys are injected directly into your config file.
</Note>

### Manual API Key

Prefer manual setup? Generate an API key:

1. Go to [herobrain.ai/api-keys](https://herobrain.ai/api-keys)
2. Click "Create API Key"
3. Copy the key (shown once)
4. Add to your MCP config (see [Manual Installation](#manual-installation-advanced))

## Troubleshooting

<AccordionGroup>
  <Accordion title="MCP tools not appearing in Claude">
    **Solution:** Restart Claude Desktop completely (Cmd+Q, then reopen)
  </Accordion>

  <Accordion title="Authentication failed">
    **Solution:** Run `npx @herobrain/mcp install` again to re-authenticate
  </Accordion>

  <Accordion title="'Command not found' error">
    **Solution:** Ensure Node.js is installed: `node --version` (requires v18+)
  </Accordion>
</AccordionGroup>
