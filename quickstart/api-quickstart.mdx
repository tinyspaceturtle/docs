# API Quickstart

Build on HeroBrain with our REST API. Production-ready in 10 minutes.

<Note>
  **Prefer SDKs?** Check out our [TypeScript](/quickstart/sdk-quickstart#typescript) and [Python](/quickstart/sdk-quickstart#python) SDKs for a better developer experience.
</Note>

## Make Your First Request

```bash cURL
curl https://api.herobrain.ai/api/v1/memories \
  -H "Authorization: Bearer hb_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Met with Sarah about Q4 roadmap planning",
    "type": "episodic",
    "metadata": {
      "person": "Sarah",
      "topic": "Q4 Planning"
    }
  }'
```

<Tip>
  **Get an API key** - Sign up at [herobrain.ai/signup](https://herobrain.ai/signup) and create a key in your dashboard
</Tip>

## Response Format

All API responses follow this structure:

```json
{
  "success": true,
  "data": {
    "id": "mem_abc123",
    "content": "Met with Sarah about Q4 roadmap planning",
    "type": "episodic",
    "created_at": 1699564800000
  },
  "metadata": {
    "request_id": "req_xyz789",
    "timestamp": "2025-11-12T10:00:00Z",
    "version": "v1"
  }
}
```

## Authentication

Include your API key in the `Authorization` header:

```bash
Authorization: Bearer hb_live_YOUR_API_KEY
```

<Warning>
  **Never expose API keys** - Use environment variables and never commit keys to git
</Warning>

### API Key Types

| Prefix | Environment | Usage |
|--------|-------------|-------|
| `hb_live_` | **Production** | Real data, billed requests |
| `hb_test_` | **Test** | Sandbox data, not billed |

### Generate an API Key

1. Go to [herobrain.ai/api-keys](https://herobrain.ai/api-keys)
2. Click "Create API Key"
3. Name your key (e.g., "Production API")
4. Select scopes (read, write, admin)
5. Copy the key (shown once!)

## Error Handling

```json Error Response
{
  "success": false,
  "data": null,
  "errors": [
    {
      "code": "VALIDATION_ERROR",
      "message": "Content is required",
      "path": "content"
    }
  ],
  "metadata": {
    "request_id": "req_xyz789",
    "timestamp": "2025-11-12T10:00:00Z"
  }
}
```

### Error Codes

| Code | Status | Description |
|------|--------|-------------|
| `VALIDATION_ERROR` | 400 | Invalid request parameters |
| `AUTHENTICATION_ERROR` | 401 | Invalid or missing API key |
| `RATE_LIMIT_ERROR` | 429 | Too many requests |
| `NOT_FOUND` | 404 | Resource not found |
| `INTERNAL_ERROR` | 500 | Server error (we're notified) |

<Tip>
  **Request IDs** - Include `request_id` when contacting support for faster resolution
</Tip>

## Webhooks

Subscribe to real-time events:

```bash
POST /api/v1/webhooks
```

```json Request
{
  "url": "https://your-app.com/webhooks/herobrain",
  "events": ["memory.created", "memory.updated", "memory.deleted"],
  "secret": "whsec_abc123"
}
```

### Webhook Events

| Event | Description |
|-------|-------------|
| `memory.created` | New memory stored |
| `memory.updated` | Memory modified |
| `memory.deleted` | Memory removed |
| `insight.generated` | New insight available |
| `vip.detected` | New VIP identified |

<Tip>
  **Webhook Signatures** - Verify requests using HMAC-SHA256 signatures
</Tip>

## Idempotency

Prevent duplicate requests using idempotency keys:

```bash
POST /api/v1/memories
Idempotency-Key: unique_key_123
```

The same key will return the same response for 24 hours.

## Versioning

The API is versioned via URL path:
